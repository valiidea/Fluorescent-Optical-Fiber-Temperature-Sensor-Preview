# 测量与验收指南

这份指南可作为自己的光纤测温实验记录框架。验收阈值应依据使用场景和双方约定填写，本预览不预设量程、精度或响应速度保证。

## 先记录条件，再比较结果

每批实验至少记录：设备与探头标识、固件版本、参数版本、环境或温槽条件、参考仪器、预热过程、采集间隔、开始与结束时间、接线变化和异常事件。涉及温度参考时，还要记录参考仪器的不确定度及传感器位置。

更换探头、改变滤波或修改参数后，应作为新工况保存。把不同工况下最好看的片段拼在一起，会失去比较意义。

## 指标的计算与解释

设有效温度记录为 x₁ … xₙ，时间戳为 t₁ … tₙ：

| 指标 | 计算方法 | 能回答什么 |
|---|---|---|
| 有效点数 | 满足有效状态且温度有限的点数 | 本次有多少可分析数据 |
| 有效段首末跨度 | 最后有效时间 − 最早有效时间 | 有效记录覆盖多长时间；中间可能有缺口 |
| 峰峰值 | max(x) − min(x) | 这段输出总变化范围 |
| 均值 | Σx / n | 这段记录的平均水平 |
| 样本标准差 | √[Σ(x − 均值)² / (n − 1)] | 围绕均值的离散程度；不足两点时不定义 |
| 参考误差 | 同工况、时间对齐的输出 − 参考温度 | 相对参考的偏差，需要参考数据 |

按记录点等权计算均值时，只有采样间隔相近，这种均值才接近时间平均值。参考对齐、异常剔除和去趋势都属于额外处理，必须披露方法与处理前后的结果。

## 建议的验收记录表

| 试验 | 需要保存的证据 | 验收条件 |
|---|---|---|
| 室温稳定段 | 完整时间序列、失败记录、环境说明 | 双方约定持续时间和波动上限 |
| 多温点升温 / 降温 | 参考与被测记录、稳定等待、探头位置 | 双方约定温点、误差和迟滞要求 |
| 重复装配 / 更换探头 | 装配过程、探头身份、重复次数 | 明确是否逐探头标定 |
| 温度阶跃 | 同步参考、原始输出、滤波配置 | 双方约定响应时间的定义 |
| 弱信号 / 断纤恢复 | 事件时间、输出状态、恢复过程 | 双方约定错误状态与恢复行为 |
| 通信异常 / 参数保存 | 请求记录、重启前后配置、失败情况 | 双方约定失败处理与持久化要求 |
| 长期运行 | 连续记录、缺失区间、环境与维护事件 | 双方约定时长、漂移及完整率 |

## 如何形成可解释的验收结论

验收前先确定温点、等待条件、参考方法、允许误差、响应时间定义和异常处理要求。试验完成后，将结论限定在实际覆盖的条件内，并分别记录通过项、未通过项和未验证项。

短时波动不能替代准确度验证；自然环境下的缓慢温度变化也不应全部解释为电子噪声。没有同步参考时，只能讨论输出变化，不能计算相对参考的误差。

本页只提供验证方法，不附实测记录或结果。详细验证资料的交付范围另行确认。
