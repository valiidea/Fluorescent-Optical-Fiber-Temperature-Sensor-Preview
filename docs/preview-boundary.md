# 公开预览与付费交付边界

公开资料用于判断技术方向和交付是否匹配；付费范围在咨询后以双方确认的清单为准。

| 内容 | 公开预览 | 付费范围讨论 |
|---|---|---|
| 测温原理与系统职责 | 概念说明和链路图 | 结合实际工程的设计解释 |
| 测量与验收方法 | 指标口径、实验记录框架 | 项目验证资料与约定的复现支持 |
| 工程设计与接入评估 | 设计取舍、硬件条件与接入问题 | 结合实际平台的适配与支持 |
| 实测记录与验证资料 | 不公开实测串口数据、曲线或报告 | 是否提供及具体范围单独确认 |
| 激励、采样与寿命估计 | 只讲模块职责 | 核心实现与工程说明，按范围确认 |
| 滤波、标定及参数 | 只讲作用与验证方法 | 实现、参数和适用条件，按范围确认 |
| 完整固件工程 | 不包含 | 可授权部分、构建环境、依赖与版本清单 |
| 固件镜像与硬件适配 | 不包含 | 指定平台适配及可交付镜像单独确认 |
| 工程辅导和问题排查 | 公开文档 | 时长、响应方式和次数另行约定 |

公开仓库没有生产固件、精确采样时序、完整寄存器表、标定数据、设备授权材料、原厂镜像或逆向重建资料；也不包含私有工程的提交历史及构建附件。公开资料集中于技术总览、系统架构和工程评估方法。

完整硬件设计、探头材料配方和母板固件不在当前默认交付范围。高温扩展、全温区准确度和长期运行性能需另外确认验证状态。

付费不自动代表取得所有权、独占权、转售权或无限期支持。第三方组件和参考资料的权利仍归其各自权利人，只能在相应许可范围内交付和使用。
