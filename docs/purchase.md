## 咨询时提供哪些信息

| 信息 | 可公开的填写示例 |
|---|---|
| 用途 | 原理学习、研发验证、已有设备二次开发 |
| 平台 | 现有 MCU、是否已有探头和模拟前端 |
| 所需内容 | 核心源码、构建说明、通信工具、标定方法或技术支持 |
| 目标条件 | 计划温区、更新速度、验证环境与开发阶段 |
| 交付时间 | 希望开始评估的时间 |

Issue 是公开入口，请勿提交客户资料、未公开原理图、设备密钥、支付凭证或私密联系方式。有保密要求时，只需说明需要私密沟通，由双方再确认渠道。

## 从评估到交付

1. **初步匹配**：通过本预览确认方向，说明已有硬件和目标。
2. **确认清单**：逐项确认可交付内容、第三方依赖、版本、已验证范围和未完成事项。
3. **确认报价与使用范围**：明确学习或商业使用、设备或项目范围、再分发限制、支持内容与交付方式。
4. **付款与私有交付**：按双方确认的约定付款，通过双方确认的私密渠道交付资料。
5. **核对与验收**：核对文件清单、版本和校验值，按约定的构建、运行或实验步骤验收。

## 可讨论的技术包

| 技术内容 | 交付前需要明确 |
|---|---|
| 测温核心与相关源码 | 具体模块、可授权范围、当前已知限制 |
| 固件工程与构建资料 | 目标硬件、工具版本、依赖、可复现构建条件 |
| 标定与验证资料 | 数据来源、探头适用性、参考条件、复现步骤 |
| 通信与主机工具 | 系统环境、接口范围、操作说明 |
| 适配与辅导 | 工作内容、支持周期、次数和验收方式 |

最终交付应有一份独立清单，说明每项是否包含、版本、使用权限和验收方法。公开页面不是无条件交付全部材料的承诺。

## 当前边界

现有工程包含嵌入式测温链路、主机工具与验证资料，但部分实现对齐、实板波形问题和长期性能验证仍有未完成项。公开预览不附实测记录；具体版本的验证范围与已知限制在交付前确认。

不默认包含完整电路设计、探头材料配方、母板固件、第三方原厂镜像及其再分发权；也不承诺已具备量产认证、全温区精度报告或对任意硬件的直接兼容。报价时应明确这些边界。
